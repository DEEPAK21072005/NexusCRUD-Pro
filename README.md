# Express CRUD Experiment

A simple **CRUD (Create, Read, Update, Delete) application built using Express.js** to understand backend fundamentals and client–server interaction.

This project is part of my learning journey, focusing on clarity, simplicity, and hands-on practice rather than complexity.

---

## ✨ Features

- Create new items  
- View existing items  
- Update item details  
- Delete items  
- Simple and clean UI  
- Express.js backend handling all CRUD operations  

---

## 🛠 Tech Stack

- Node.js  
- Express.js  
- HTML  
- CSS  
- JavaScript
